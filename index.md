# Communication Theory Primer

Welcome to this project website. It introduces non-technical audiences to major schools of communication theory and shows how those ideas can help diagnose communication problems in the 21st century, especially those involving artificial intelligence.

<div class="summary-card" role="note" aria-label="Project summary">
This site is a structure-first draft. You can replace all text, examples, and references with your own analysis.
</div>

## Project purpose

The goal is to make everyday communication challenges visible and understandable by applying foundational theory. Each section provides a different lens that can be used for personal and professional decision-making.
