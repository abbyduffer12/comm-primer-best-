# How I built this site

This page explains the process behind the website stack, layout, and writing plan.

## Tool stack and layout

The site uses Jekyll with a custom layout and CSS palette designed for readability, clear navigation, and accessibility. The information architecture separates each theory lens into its own page so readers can compare frameworks quickly.

## Content workflow

This repository is prepared so the owner can replace the placeholder text with original analysis, references, and examples.

## Agent involvement

A coding agent generated the initial Jekyll structure, page templates, navigation, workflow configuration, and README documentation based on project requirements. Final analytical content and interpretation decisions are reserved for the site author.
